# remedy-auto-logout
Cierre de sesión de Remedy por inactividad
Política de privacidad – Remedy Auto Logout

Remedy Auto Logout es una extensión destinada a detectar periodos de inactividad en BMC Remedy y cerrar automáticamente la sesión tras el tiempo configurado.

La extensión no recopila, transmite, vende ni comparte datos personales con el desarrollador ni con terceros.

La extensión utiliza almacenamiento local del navegador únicamente para guardar temporalmente el momento de la última actividad del usuario y el estado del temporizador de inactividad. Esta información permanece en el dispositivo del usuario y no se transmite a servidores externos.

La extensión únicamente funciona en el dominio https://atomgencat.onbmc.com/ y utiliza los permisos necesarios para detectar actividad, mostrar el aviso de inactividad y ejecutar el cierre de sesión de Remedy.

No se recopilan credenciales, contraseñas, cookies, tokens de autenticación, contenido de formularios ni información personal.

Los datos utilizados localmente por la extensión no se utilizan para publicidad, análisis, perfilado ni ningún otro propósito distinto del funcionamiento del cierre automático de sesión.

Finalidad de la extensión
Remedy Auto Logout detecta periodos de inactividad en BMC Remedy y, tras mostrar un aviso previo, ejecuta automáticamente el cierre de sesión si el usuario continúa inactivo.

Actividad del usuario
La extensión procesa localmente señales de actividad como clics, pulsaciones de teclas, desplazamiento y otras interacciones únicamente para determinar si el usuario permanece activo.

La extensión no registra el contenido de las teclas pulsadas ni almacena un historial de las acciones realizadas por el usuario.

Contenido del sitio web
La extensión inspecciona localmente determinados elementos de la interfaz de BMC Remedy con el único objetivo de identificar el control de cierre de sesión y activarlo cuando finaliza el periodo de inactividad configurado.

Almacenamiento local
La extensión utiliza el almacenamiento local del navegador únicamente para guardar temporalmente el momento de la última actividad y el estado del temporizador de inactividad.

Datos que no se recopilan
La extensión no recopila contraseñas, credenciales, cookies, tokens de autenticación, información financiera, información sanitaria, ubicación, comunicaciones personales ni historial de navegación.

Transmisión y compartición de datos
La información procesada por la extensión permanece en el dispositivo del usuario. No se transmite al desarrollador ni a servidores externos y no se vende ni comparte con terceros.

Publicidad, analítica y perfilado
Los datos procesados localmente no se utilizan para publicidad, analítica, seguimiento, perfilado, evaluación crediticia ni ningún propósito diferente del funcionamiento de la extensión.

Ámbito de funcionamiento
La extensión está limitada al dominio https://atomgencat.onbmc.com/ y no actúa sobre otros sitios web.
